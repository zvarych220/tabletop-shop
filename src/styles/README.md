# CSS Modules Structure

## Files:
- **variables.css** - Design tokens (colors, fonts, shadows, radii)
- **base.css** - Reset, base styles, typography
- **layout.css** - Layout components (container, grid, sections)
- **buttons.css** - Button components and variants
- **forms.css** - Form inputs, validation, fields
- **cards.css** - Game cards, product cards
- **header.css** - Site header, navigation, cart badge
- **cart.css** - Cart drawer and cart components
- **catalog.css** - Catalog page, filters, grid
- **game-details.css** - Game details page styles
- **checkout.css** - Checkout form and order creation
- **orders.css** - Orders list, order table, filters
- **auth.css** - Login, register, profile pages
- **favorites.css** - Favorites page and wishlist
- **responsive.css** - Media queries and breakpoints

All modules are imported in `/src/index.css`
